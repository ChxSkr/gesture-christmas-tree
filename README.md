# 手势圣诞树 · Gesture Christmas Tree

用手势实时操控的粒子圣诞树特效。纯前端单页，无需构建、无需联网。

## 快速开始

双击 `start.cmd`（自动起本地服务器并打开浏览器）。

或手动：

```bash
python -m http.server 8777 --bind 127.0.0.1
# 打开 http://localhost:8777/index.html
```

> 摄像头只在 `https://` 或 `localhost` 下可用。直接双击 `index.html`（`file://`）时摄像头会失败，页面自动降级为动画模式。

演示模式（无摄像头也能看效果）：`http://localhost:8777/index.html?demo=1`

## 手势映射

| 手势 | 效果 |
|---|---|
| 五指张开 / 握拳 | 树冠张开与收拢 |
| **右手拇指捏合食指后左右拖动** | 抓住树转动，松手甩出惯性 |
| 手掌上下移动 | 视角俯仰 |
| 双手拉开 / 靠拢 | 镜头推近与拉远 |

旋转是**抓取拖动**：捏合（拇指与食指）超过阈值即"抓住"，此后手的水平位移按 `1 个画面宽度 = 1 圈` 换算成树的角度；松开后保留甩出的角速度，靠阻尼滑行停下。系统优先使用**右手**，没有右手时退回检测到的第一只。捏合判定带 0.78 / 0.55 双阈值迟滞，避免手指微抖导致反复抓放。

甩动时还有三重联动：树身按高度递增地**扭转**（螺旋被拧紧/拧松）、整体向运动反方向**侧倾**、彩灯闪烁频率与亮度随转速上升；停下来 1 秒后恢复自动旋转。

页面右下角实时显示摄像头画面；**手部 21 个关键点骨架会叠加在主画面上**——青色连线、白色关节、黄色指尖光点、掌心十字准星，用加色混合绘制，像投影在树上的光而不是贴纸，不会糊住场景。骨架按「摄像头画面 cover 铺满窗口」换算，再以掌心为中心缩到 0.6 倍，位置仍与真实的手一一对应。

下方 `HAND TRACKING · N` 显示识别手数，再下面的横条指示当前旋转方向与强度。

鼠标拖拽可替代手掌位移。**点击任意一朵雪花可以把它点掉**（会有一圈光晕反馈），1.1 秒后它会在别处换个起点重新落下，所以点不完。`H` 隐藏界面（连同骨架），`D` 切换虚拟手势演示。

若觉得转得太快或太慢，调 `index.html` 里的 `ROT_PER_SCREEN`（默认 `Math.PI * 2`，即横扫一个画面宽度转一圈）；抓取灵敏度由 `GRAB_ON`（0.78）/ `GRAB_OFF`（0.55）控制。

## 参数调节

点右上角齿轮（或按 `P`）打开侧边面板。所有改动**实时生效**，并记在 localStorage 里，刷新不丢；底部有"恢复默认"。

| 分组 | 参数 | 作用 |
|---|---|---|
| 手势 | 旋转灵敏度 | 手横扫一屏对应树转几圈 |
| | 捏合抓取阈值 | 越大越难触发抓取 |
| | 松手惯性 | 越大松手后滑行越久 |
| 动画 | 自动旋转速度 | 无操作时的自转角速度 |
| | 恢复自转延迟 | 停手后多久恢复自转 |
| | 扭转强度 | 甩动时树身拧转的幅度 |
| 视觉 | 树体粒子 | 2,000 ~ 9,000 |
| | 彩灯亮度 | |
| | 雪花数量 | 300 ~ 2,200 |
| | 雪花速度 | |

粒子数量用 `geometry.setDrawRange()` 截断，**不重建几何体**，所以拖滑块是零卡顿的。为此粒子虽然仍按螺旋连续生成（保住层次感），写入数组时却用互质步长打乱了顺序——否则截断只会剩下树的底部。

## 技术实现

```
摄像头 → MediaPipe HandLandmarker（21 关键点）→ 手势参数（0~1）→ Three.js 粒子场景
```

**识别**：`@mediapipe/tasks-vision` 的 `HandLandmarker`，VIDEO 模式最多 2 只手。张合度用「指尖到腕距离 ÷ 掌宽」计算，与手的朝向无关，比判断指节上下位置稳得多。

**平滑**：所有参数走 EMA（系数 0.15）+ 0.0035 死区，手静止时画面完全静。

**渲染**：三个 `Points` 对象（树体 9000 / 彩灯 240 / 雪花 2200），自定义 Shader 做加法混合发光。

**雪花**：canvas 现画的六角雪花纹理（带柔光底 + 1.5px 模糊，远处自动退化成光点），三层尺寸纵深共 2200 片。**下落速度全场统一**（`uSpeed` 固定 1.0，不随机、不受手势影响），下落、轻微横摆、自转全部在着色器里算，CPU 每帧只更新 uniform；转动时 `uWind` 会把雪整体吹偏。

**解耦**：手势推理限频约 22fps，渲染锁 60fps。

## 目录

```
index.html                     主程序（HTML + CSS + GLSL + JS 全在一个文件）
start.cmd                      一键启动
vendor/three.module.js         Three.js r160
vendor/vision_bundle.mjs       MediaPipe Tasks Vision
vendor/wasm/                   MediaPipe WASM 运行时（SIMD + 非 SIMD）
models/hand_landmarker.task    手部关键点模型
```

全部依赖已本地化，断网可用。

## 已知限制

- 手离摄像头超过约 1.5 米时关键点会漂移，建议距离 50~80 cm。
- 强逆光或纯色背景下检测率下降。
- 首次加载需解析约 9 MB WASM，低配机器上约 2~4 秒（此间场景已可交互）。
